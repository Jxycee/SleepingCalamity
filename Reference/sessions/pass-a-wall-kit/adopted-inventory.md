## Megascans finder

Lives on `main` (commit cd75c24e), not in this worktree. Read it with `git show main:Tools/art/sc_megascans_find.py`. The index is `Reference/megascans/megascans_index.csv` (18,870 rows, Oct 2024 dump; newer assets missing).

Search command (stdlib Python, run from repo root):

```
python Tools/art/sc_megascans_find.py "gravestone" --type 3d --limit 20
python Tools/art/sc_megascans_find.py mossy rock --type surface --full
python Tools/art/sc_megascans_find.py --id vgpochzia
python Tools/art/sc_megascans_find.py --downloaded
```

Words are AND-matched against name, categories and tags. `--type` takes 3d, 3dplant, surface, atlas or brush. `--downloaded` lists what is in the Epic Launcher library.
