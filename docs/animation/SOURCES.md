# Animation sources

The hero's clips (docs/PHASE1.md 6.5, P29). Everything lives under `Assets/_Project/Content/Animation/<Source>/`. Import settings are applied by
`AnimationImportBuilder` (part of `ProjectBuilder.RunAll`), never by hand. The controller `HeroAnimator.controller` is generated by `HeroAnimatorBuilder` from the
slot table `HeroClipTable`; do not edit it in the Animator window.

## Import rules
- Every FBX is Humanoid. Quaternius and Kevin Iglesias: avatar created from the file itself. Mixamo without-skin clips: avatar copied from `YBot.fbx`.
- Quaternius: Bake Axis Conversion on (the pack's own Unity setup sheet), every clip named `*_Loop` loops. Mixamo: idles loop, transitions do not.
- Every clip bakes root rotation, height and XZ into the pose, and the hero's Animator has Apply Root Motion off: the CharacterController moves the hero, never a clip.

| Axe hit 1 / hit 2 (mirrored) | Quaternius Sword_Attack |

| Staff hit 1 / hit 2 (mirrored) | Quaternius Spell_Simple_Shoot |

Attack, dodge and (via the drivers) hurt clips play by progress: the attack states take their time from the combat clock (`AttackFrame / TotalFrames`, the owner's machine or
the replicated swing clock on a remote copy), so the clip's length never has to match the attack's frame data.
